# GujaratWheels Flutter App

## Run
1. Install Flutter SDK.
2. Open this folder in VS Code or Android Studio.
3. Run `flutter pub get`
4. Run `flutter run`

## Included
- Gujarati + English UI
- Cars, Tractors, Commercial Vehicles, Bikes
- Listing browsing and vehicle details
- Sell vehicle form
- My Ads screen
- Mobile OTP UI placeholder
- Profile screen
